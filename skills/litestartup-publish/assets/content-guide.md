# Content Guide

Conventions the LiteStartup Skill (and you) apply to **every** piece of content:
website pages, blog posts, docs, changelog, campaigns — and any future content.

> **Facts** (name, tagline, pricing, version, URLs) are the single source of truth in
> [`shared.yml`](./shared.yml). Always use those values — never hardcode a fact that
> lives there, and never contradict another page.

## Voice & tone
- Clear, concise, factual. Avoid hype and filler.
- Write for busy founders and developers.

## Terminology
- Use the canonical terms defined in `shared.yml` → `terminology` (and avoid the listed
  alternatives) so the same thing is always named the same way.

## Formatting
- Sentence-case headings, short paragraphs, prefer concrete examples over adjectives.

## Do / Don't
- **Do**: reflect `shared.yml` facts (pricing, version, URLs) exactly.
- **Don't**: invent prices/versions, or state a fact that conflicts with `shared.yml`.
